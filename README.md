# EMOTION-DETECTION

A Streamlit-based web application that detects emotions from text using a pre-trained DistilBERT model.

## Features
- **Real-time Analysis**: Type text and get instant emotion predictions.
- **Visualizations**: Confidence bar charts for detected emotions.
- **Training Script**: Optional script to fine-tune your own emotion detection model.

## Installation

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

### Run the App
```bash
streamlit run src/app.py
```

### Train Custom Model (Optional)
```bash
python src/train.py
```
